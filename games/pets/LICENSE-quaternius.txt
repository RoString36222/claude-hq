Changes made for Claude HQ (CC0 asks for none; noted for clarity): converted to binary glTF with three.js r186
(FBXLoader / GLTFExporter); the meshes merged into one skinned mesh whose materials became a per-vertex "_ROLE"
(main, second, belly, eye, dark, white, pink, ivory) so each pet can be recoloured; normals dropped (flat shaded);
animations cut to idle / look / sniff / walk / run (dogs) and idle / walk / run / roar / jump (dinosaurs),
resampled to 15 fps, scale tracks and non-deforming bones' tracks removed.
