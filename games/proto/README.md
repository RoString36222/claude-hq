# games/proto: development pages for the 3.41 realism work

Standalone pages (serve the repo root with `python3 -m http.server`, open /games/proto/<page>.html); not served by the HQ app.

- realism.html: the original bike + car + rider prototype
- garage.html: every catalogue vehicle (?kind=&id=&view=&lod=&starter=1)
- people.html: a lineup of character specs
- exo.html: the exosuit frames and flight modes
